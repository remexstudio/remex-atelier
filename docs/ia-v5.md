## Commercial thesis (do not dilute)

Remex is not a model lab and not a four-product shop.

Remex is a boutique that designs, ships, and tightens custom AI agents for one painful company workflow at a time — with a human gate as the product surface.

**Buyer:** founder / ops lead / GM whose desk already feels broken.

**Vs Copilot Studio / Agentforce / Big-4:** they sell a platform. Remex designs the **job** and the **gate** for a seat that does not fit a template.

An angel or other serious reader in their 60s must see, in one sitting:

1. A repeatable offer (Layer A — services catalog)
2. A path from first seat to next seats / later tools (engagement + Now / Next / Later)
3. Proof of method via examples (Layer B — not SKUs)
4. How risk is held (gate + record)
5. How to start (Start a brief)

This is not a student portfolio of four widgets.

**Extensibility** is one section, never a shipped SaaS claim. Label future as direction only.

English is a **build constraint**, never a market claim. No founder legal name. No personal site.

## 2. Layer A — Services catalog (primary)

Layer A is the commercial surface. **Home shows services before examples.** `/services` is the full catalog. Examples never outrank the offer.

### 2.1 Agent product design

| Field | Lock |
| --- | --- |
| Who | The founder, ops lead, or GM who owns the broken desk — and the named person who will approve. |
| Deliverable | A written job: who sits in the seat, what arrives, what “done” looks like, and the gate the agent cannot cross. |
| Refuse | A vague assistant for everything. A seat with no named approver. Work that should not be an agent. |
| Done state | Job and gate agreed. The brief is ready to build. No silent execution. |

Design happens before tools enter the room. If a smaller tool is honest, say so and walk away.

### 2.2 Agent build

Mechanism (verbatim bullets in `docs/copy-locks.md`): **Propose → Approve → Record.** A human still decides.

| May | May not |
| --- | --- |
| Draft | Silently move money |
| Retrieve | Silently publish |
| Route | Silently delete |
| Classify | Execute irreversible work without a named person |
| Queue | Cross the gate drawn in the brief |

Build ships the **first seat** — one painful workflow, one agent, one gate. Not a platform. Not four SKUs.

### 2.3 Agent operations

After the first seat ships:

- Run evals against the job, not against a generic model scoreboard
- Tighten the gate where the desk still flinches
- Improve the record so a proposal can be reopened
- Open a **next seat only when the first gate holds**

Operations is not an hours factory and not a staffed body shop.

### 2.4 Engagement shape (labels locked)

**Start a brief → Design job+gate → Ship first seat → Operate / decide second seat**

| Beat | Meaning |
| --- | --- |
| Start a brief | Buyer names the painful workflow, who approves, what the agent may never do, and what record must stay |
| Design job+gate | Studio writes the job and the gate; refuse if the seat should not be an agent |
| Ship first seat | Build the Propose → Approve → Record loop for that seat only |
| Operate / decide second seat | Tighten evals, gates, and records; a second seat opens only if the first gate holds |

### 2.5 For / Not for

**For**

- A founder, ops lead, or GM whose desk already feels broken
- One painful workflow with a human who must stay in the loop
- A seat that does not fit a Copilot Studio / Agentforce / Big-4 template

**Not for**

- An hours factory or staffed body shop
- A generic chatbot or chatbot widget
- “ChatGPT for X” as an offer
- A cloud-migration mill or outsourcing body shop
- Replacing the client team
- Buyers who want a four-SKU catalog or a platform of templates
- Compliance theater (SOC 2 / ISO badges we do not have)

### 2.6 Trust stance

Print the locked paragraph from `docs/copy-locks.md` once on `/services` and once on `/approach` (or contact). Do not paraphrase in UI. No fake compliance badges. No invented week counts or prices.

## 3. Layer B — Selected examples (proof of method, not SKUs)

Examples prove the method. They are not the offer. Index label: **Selected examples** — never “Products” or “Our agents.”

Keep existing URL slugs. Change **display names** only.

| URL slug (keep) | Display | Was (V3 shop name) | Gate fact |
| --- | --- | --- | --- |
| `atelier-concierge` | Demand desk | Atelier Concierge | Human before pay |
| `ledger-clerk` | Knowledge desk | Ledger Clerk | Human before execute corpus change |
| `morning-remex` | Attention desk | Morning Remex | Priority / Watch / Noise; human before send |
| `exception-copilot` | Exception desk | Exception Copilot | Human before money moves |

Do not sell these four as “the agents we build.” Each page must end by sending the reader back to the next brief.

### 3.1 Page shape (every `/work/*`)

1. **Context** — seat, buyer, why the desk broke
2. **Narrative** — 500–800 words; one job; unique abilities, gate, record, refusal (V3 uniqueness seeds still apply; display name and SKU framing do not)
3. **Stills** — 4–6 captioned stills as media (not chip-as-page)
4. **Closer (verbatim):** This is one seat. The next brief will be a different job.

Footer on every example: **Studio study. Client identity anonymized.**
CTA: **Start a brief.** → `/contact`

### 3.2 Desk seeds (method proof)

Facts stay distinct. Copy must not be interchangeable across desks.

**Demand desk** — `/work/atelier-concierge`

- Seat: high-touch demand / concierge desk
- Pain: skin, occasion, and fit notes scatter across fittings, holds, and aftercare
- Agent may: map occasion → one hero; stage a try-on still; draft the bag
- Gate: human before pay; no charge without approval
- Record: consult thread + ticket
- Refusal: invent catalog SKUs; charge without approval

**Knowledge desk** — `/work/ledger-clerk`

- Seat: controller / knowledge desk on a fixed corpus
- Pain: the same source hunt buries the team every close
- Agent may: answer from corpus only; attach citations; draft a Propose package
- Gate: human before execute corpus change; Propose never Execute
- Record: ask, citation, and decision in one audit log
- Refusal: answer outside corpus; Execute ledger or corpus writes

**Attention desk** — `/work/morning-remex`

- Seat: operator desk turning overnight threads into one morning packet
- Pain: overnight mail arrives without a single readable brief
- Agent may: sort Priority / Watch / Noise; draft in two tones; escalate
- Gate: human before send; never auto-publish
- Record: brief + draft + escalate decision linked
- Refusal: auto-publish digests or posts

**Exception desk** — `/work/exception-copilot`

- Seat: ops / CX lead clearing exception queues
- Pain: exceptions pile faster than policy can be reread
- Agent may: rank the queue; suggest a policy disposition; draft the case note
- Gate: human before money moves; human for refunds
- Record: case timeline (policy cite + decision)
- Refusal: issue refunds or move money without a human

### 3.3 Optional on `/work` — other seats this method fits

Label clearly: **method fits, not shipped products.**

- Support triage
- Vendor onboarding
- Invoice exceptions
- Sales follow-up
- Internal policy Q&A

No case pages, no SKUs, no “coming soon” product grid.

## 5. Visual / mobile contract

Reference for later tickets. Grammar awareness from Apple / Emil / GSAP / cinematic / zero-jank / review-animations. No app work in V5-0.

### 5.1 Materials

| Token | Value | Use |
| --- | --- | --- |
| Canvas | `#ffffff` | Default page / product stage |
| Gutter | `#f5f5f7` | Section gutters, rails, soft bands |
| CTA | existing `--cta` | CTA fill only — never a page wash |

- **Type:** SF-like sans for UI and body. Large **negative-tracking** display. Do not use warm-paper magazine serif as the primary commercial grammar.
- **Nav:** 44–48px sticky frosted bar (`backdrop-filter` blur + saturate). Hairline under the bar.
- **Rules:** hairlines, not heavy cards. Stills are **media** (product-page frames), not chip stacks pretending to be a page.
- **Accent:** CTA only. No purple mesh, no neon, no robot illustration as “tech.”
- **Tech feel** = gate stills + type + chapter rhythm. Not neon. Not robots. Not a model-lab dashboard.

### 5.2 Kill list (visual)

- Warm-paper magazine (`#f4f0e8` paper) as the **primary** marketing grammar
- Chip-as-page (a screen made of pills, tags, and slogan chips)
- Six isomorphic full-bleed pins
- Horizontal chip rails as a page hero
- Purple gradient AI-SaaS templates
- Inter-on-white generic AI landing

### 5.3 Modules and pin

- Varied modules. Same page must use **≥3 layout grammars**.
- **Pin only to reveal a NEW fact.** No pin that restates a slogan.
- Default = shallow scroll. Nav and footer always reachable.
- Motion: `transform` and `opacity` only. UI chrome under 300ms. Press `scale(0.97)` on `:active`. Hover motion only behind `@media (hover: hover) and (pointer: fine)`.
- **Hard ban (scroll stack):** no Lenis, no ScrollTrigger `normalizeScroll`, no `body` / `html` overflow lock while pinned. Native scroll. Zero jank.
- `prefers-reduced-motion`: full payload still readable (static stack). Not a slogan subset.

### 5.4 375 contract

- Collapsed nav (no four-link hairline row that wraps into a chip rail)
- Stacked modules; still above copy
- **No horizontal chip rails**
- Hit targets **≥44px**
- Forms usable: visible labels, full-width fields, no horizontal trap
- Type remains readable; do not squeeze display under a usable body size

### 5.5 Angel / serious-reader scan (60s)

In one viewport sequence the reader must find: offer, path, proof, risk hold, start. Type and stills do that work. Do not hide the offer behind motion.
